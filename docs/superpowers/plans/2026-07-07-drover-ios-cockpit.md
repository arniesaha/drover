# Drover iOS Cockpit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Drover, an iPhone-first SwiftUI cockpit for the Nexus harness fleet: session list with attention states, native chat with turns/approvals, launch screen, SwiftTerm terminal, and local needs-you notifications.

**Architecture:** All non-UI logic lives in a local Swift package `NexusKit` (models with tolerant decoding, `NexusClient` actor for REST/WS, `@Observable SessionStore`, Keychain, Notifier protocol) with headless unit tests; the app target is thin SwiftUI over the store. The Xcode project is generated by XcodeGen from a committed `project.yml`.

**Tech Stack:** Swift 6.2 / Xcode 26.2, SwiftUI, Swift Testing (`@Test`), URLSession (+`URLSessionWebSocketTask`), XcodeGen (installed at /opt/homebrew/bin/xcodegen), SwiftTerm (SPM, the only third-party dependency), iOS deployment target 18.0, simulator runtime iOS 26.2.

**Spec:** `docs/superpowers/specs/2026-07-07-drover-ios-cockpit-design.md`

## Global Constraints

- Product name **Drover**, bundle id `com.arnab.drover`; the word "Nexus" never appears in UI copy (package/internal names keep NexusKit per issue #199 staging).
- Only third-party dependency: SwiftTerm. Everything else first-party Apple.
- Free-account signing: `CODE_SIGN_STYLE: Automatic`, no team id committed; simulator builds need no signing.
- All server calls carry `Authorization: Bearer <token>`; the token lives in Keychain only — never in UserDefaults, never logged, never rendered back in UI (Settings shows "configured ✓").
- Tolerant decoding everywhere: unknown message/session fields or types must degrade to fallbacks, never throw out of the decode path, never crash.
- Message type vocabulary (from spec 1): `assistant_output`, `user_input`, `tool_action`, `tool_result`, `approval_prompt`, `approval_response`, `status`, `error`, `raw`. Session `awaiting` ∈ {`input`, `approval`, NULL}; `status` ∈ {starting, running, completed, terminated, errored}.
- Build command: `cd apps/drover && xcodegen generate && xcodebuild -project Drover.xcodeproj -scheme Drover -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build`
- Test command: same with `test` instead of `build` (NexusKit tests run in the app test host). Quiet with `-quiet`; expected result line: `** TEST SUCCEEDED **`.
- TDD for every NexusKit unit; SwiftUI views are exercised by build + the store they render.
- Commit after every task; `git add apps/drover` paths explicitly (the generated `Drover.xcodeproj` is git-ignored).

```swift
public enum AttentionState: String, Sendable {
    case needsApproval, needsInput, working, done, errored
}

public struct HostSummary: Sendable, Identifiable, Decodable {
    public var id: String        // host_id
    public var displayName: String
    public var status: String    // "online"/"offline"
    public var harnesses: [String]  // enabled preset names from capabilities
}

public struct SessionSummary: Sendable, Identifiable, Decodable, Equatable {
    public var id: String        // session_id
    public var hostID: String
    public var harness: String
    public var mode: String      // "pty" | "structured" (nil→"pty")
    public var status: String
    public var awaiting: String?
    public var cwd: String?
    public var lastActivity: Date?
    public var attention: AttentionState { get }  // derived, spec rules
    public var isStructured: Bool { get }
}

public struct HarnessSnapshot: Sendable, Decodable {
    public var hosts: [HostSummary]
    public var sessions: [SessionSummary]
    public var cwdSuggestions: [String]
}

public struct HarnessMessage: Sendable, Identifiable, Decodable, Equatable {
    public var id: String        // event_id
    public var seq: Int
    public var type: MessageType
    public var role: String
    public var text: String
    public var turnID: String?
    public var timestamp: Date?
    public var payload: [String: JSONValue]  // tolerant free-form
}

public enum MessageType: String, Sendable {
    case assistantOutput = "assistant_output", userInput = "user_input"
    case toolAction = "tool_action", toolResult = "tool_result"
    case approvalPrompt = "approval_prompt", approvalResponse = "approval_response"
    case status, error, raw
    case unknown  // any unrecognized wire string decodes to this
}

public enum JSONValue: Sendable, Equatable, Decodable {
    case string(String), number(Double), bool(Bool), null
    case array([JSONValue]), object([String: JSONValue])
    public var stringValue: String? { get }
    public var boolValue: Bool? { get }
    public var objectValue: [String: JSONValue]? { get }
}
```

- Attention derivation (single source of truth, mirrors the web/backend rules): terminal `status` ∈ {completed, terminated} → `.done`; `errored` → `.errored`; else `awaiting == "approval"` → `.needsApproval`; `awaiting == "input"` → `.needsInput`; else `.working`.
- All decoders are hand-written `init(from:)` with defaults: missing `mode` → "pty", missing/garbage `type` → `.unknown`, missing seq → 0, unparseable dates → nil. Decoding a whole array must not fail because one element is bad — provide `static func lenientArray(from: Data, key: String) -> [Self]` helpers where the wire wraps lists (`{"messages": [...]}`, `{"hosts": [...], "sessions": [...]}`); a bad element is skipped, never fatal.
- Date parsing: ISO-8601 with fractional seconds AND without (two formatters, try both).

```swift
public enum NexusError: Error, Equatable {
    case unauthorized                    // 401
    case conflict(String)                // 409 body "error" text
    case badRequest(String)              // 400 body "error" text
    case transport(String)               // URLError etc.
    case decoding(String)
}

public actor NexusClient {
    public init(config: ServerConfig, token: String,
                session: URLSession = .shared)
    public func snapshot() async throws -> HarnessSnapshot            // GET /harness
    public func messages(sessionID: String, afterSeq: Int) async throws -> MessageBatch
    public func createSession(hostID: String, harness: String, mode: String,
                              prompt: String?, cwd: String?) async throws -> String  // session_id
    public func sendTurn(sessionID: String, text: String) async throws -> String     // turn_id
    public func answerPermission(sessionID: String, requestID: String,
                                 decision: String, note: String?) async throws
    public func interrupt(sessionID: String) async throws
    public func terminate(sessionID: String) async throws
    public func healthz() async throws -> Bool                        // unauthenticated
    public nonisolated func streamRequest(sessionID: String) -> URLRequest   // for Task 5 WS
    public nonisolated func terminalRequest(sessionID: String) -> URLRequest // for Task 9 WS
}
```

- Every authed request sets `Authorization: Bearer <token>` and `Content-Type: application/json` on bodies. Error mapping: 401 → `.unauthorized`; 409 → `.conflict(text)`; 400 → `.badRequest(text)` where text is the JSON body's `error` field (fallback to raw body). Routes (exact, from the deployed API): `GET /harness`, `GET /harness/sessions/<id>/messages?after_seq=N`, `POST /harness/hosts/<hostID>/sessions`, `POST /harness/sessions/<id>/turns`, `POST /harness/sessions/<id>/permission`, `POST /harness/sessions/<id>/interrupt`, `POST /harness/sessions/<id>/terminate`, `GET /healthz`. `streamRequest`/`terminalRequest` build ws URLs by swapping the scheme to `ws` and appending `/stream` / `/terminal`, bearer header included.

`Support/MockURLProtocol.swift` — the standard pattern:

```swift
import Foundation

final class MockURLProtocol: URLProtocol {
    nonisolated(unsafe) static var handler: (@Sendable (URLRequest) -> (Int, Data))?
    override class func canInit(with request: URLRequest) -> Bool { true }
    override class func canonicalRequest(for request: URLRequest) -> URLRequest { request }
    override func startLoading() {
        guard let handler = Self.handler else { return }
        let (status, body) = handler(request)
        let response = HTTPURLResponse(url: request.url!, statusCode: status,
                                       httpVersion: nil, headerFields: nil)!
        client?.urlProtocol(self, didReceive: response, cacheStoragePolicy: .notAllowed)
        client?.urlProtocol(self, didLoad: body)
        client?.urlProtocolDidFinishLoading(self)
    }
    override func stopLoading() {}
    static func session() -> URLSession {
        let cfg = URLSessionConfiguration.ephemeral
        cfg.protocolClasses = [MockURLProtocol.self]
        return URLSession(configuration: cfg)
    }
}
```

```swift
public actor MessageStream {

    /// Emits history first (REST from afterSeq 0), then live WS frames, deduped

    /// REST catch-up from the last seen seq. Emits .connectionChanged events.

    public func stop()

    case message(HarnessMessage)
    case connection(Bool)   // false while reconnecting
```
